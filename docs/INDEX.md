This folder contains every long-form document about the Warranty Telehandler Yard application.
The canonical `README.md` and `REPORT.md` live in the project root; the copies here are kept in
lockstep so the documentation library is self-contained.

## Sync policy

`README.md` and `REPORT.md` are canonical at the project root. The copies in this folder are
identical mirrors. Whenever the root files change, the docs/ copies must be updated in the
same commit. There is no automated sync; doing it manually keeps the diff visible.

A future improvement (tracked in IMPROVEMENTS.md) would be a pre-commit hook that copies the
two files automatically.
