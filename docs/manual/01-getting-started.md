# 1. Getting started

Welcome to **WTY** (Warranty Telehandler Yard) — the warranty-claims dashboard for the JCB LDL division. This page tells you what it is, who should use which part of it, and what to do in your first 5 minutes.

## What this app is for

WTY ingests the standard `claims.csv` export and turns it into a live dashboard that answers questions your warranty team asks every day:

- *Where is claim volume heading this month?*
- *Which models, parts and suppliers are generating the most claims?*
- *How did the Jan-2025 vetting-manager change affect outcomes?*
- *Are we accepting too few claims, or rejecting too many?*
- *Which individual machines have a history of recurring claims?*

Everything is **local and air-gapped**. The dashboard reaches MongoDB on `localhost:27017` and serves the React UI from the same Node process. **No AI is involved** — every narrative on screen is produced by deterministic rules in the source code. See the dedicated [AI-free operation doc](../AI-FREE-OPERATION.md) for the full audit.

| Admin / data steward | **Admin** route — upload a new CSV |

## First 5 minutes

1. Open the dashboard at <http://localhost:4000/> (production) or <http://localhost:5173/> (dev).
2. Look at the 8 **KPI tiles** at the top: total claims, True Accept rate, Reject rate, Z-Code rate, DOA rate, Pending vets, Avg hours-to-fail, Active models.
3. Hover any tile's **(i) icon** to see what's behind the number.
4. Read the 6 **headline cards** in the Overview tab — auto-generated bullet points highlighting the most important changes in your data.
5. Use the **filter bar** to narrow to a model / country / supplier you care about. Every chart and table reacts.

## When something looks broken

1. Hover the **(i)** icon on the widget — it usually explains why the value is what it is.
2. Check the active filter bar — is some chip narrowing the data you didn't expect?
3. Try a wider date range using the **quick-pick chips** in the date strip.
4. Read the matching deep doc in [`docs/pages/`](../pages/).
5. Section 9 ([Troubleshooting & FAQ](09-troubleshooting)) of this manual has the most-common gotchas.
